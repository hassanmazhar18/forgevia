Questions? Answers.

Is Forgevia really free?

Yes. The free plan has real limits (5 projects, 1 running app) but no time bomb. Build, publish, audit and scrape at no cost.

What languages can I host?

Static HTML/CSS/JS instantly, plus Python 3 and Node.js apps as long-running processes. Dependencies from requirements.txt / package.json install automatically on publish.

Can I use my own domain?

Yes — add it under project settings, copy the DNS records to your registrar, verify, done. SSL is automatic.

How does the SEO auto-fix work?

It parses every HTML file in your project and inserts missing essentials: charset, viewport, lang, title, description, Open Graph, canonical, alt text, lazy-loading, defer on scripts, noopener on external links. You review the diff before publishing.

Is the scraper legal to use?

Scraping publicly available data is generally legal, but you're responsible for respecting robots.txt, terms of service and rate limits of the sites you target.

Can I export my work?

Always. Download any project as a ZIP, export analytics/forms/scrapes as JSON or CSV. No lock-in.
